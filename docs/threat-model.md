## Схема меж довіри

```text
browser client (недовірений ввід, cookie додається автоматично)
       │ HTTP localhost:5080 у Development, HTTPS очікується в production
       ▼
ASP.NET Core API (validation, authn/authz, antiforgery, rate limiting, logging)
       │ connection string / EF Core / Npgsql
       ▼
PostgreSQL у Docker Compose (127.0.0.1:54329)

repository + NuGet ──► dotnet restore --locked-mode / build
environment (SeedUsers__Password, ASPNETCORE_ENVIRONMENT) ──► API startup
```

## Очікувані властивості на межах

| Межа                      | Очікувана властивість (усі рівні)                                                                                                                                 | Конкретний test або перевірка (добрий і відмінний)                                      |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| browser→API               | Змінювальний запит із cookie без валідного request token відхиляється без зміни стану. Текст користувача не виконується як код. Reporter не бачить чужий інцидент | REG-CSRF-01, REG-XSS-01 (`tests/browser/description-dom.js`), `Lab04AuthorizationTests` |
| API→PostgreSQL            | Параметр пошуку не змінює структуру SQL                                                                                                                           | `SearchMechanicsTests`, S-02 з ЛР 2                                                     |
| repository→build          | Tracked files не містять реальних credentials, restore не змінює lockfile непомітно                                                                               | `git grep` з етапу 1, п. 3, `dotnet restore SecureLab.sln --locked-mode`                |
| environment→configuration | У Production не діє Development-конфігурація, reset заборонено, помилка не розкриває внутрішніх деталей                                                           | Доказ `Hosting environment: Production` і відмова `--reset-database` (етап 1, п. 4)     |

Відмінний рівень: у `docs/security-review.md` простежте для ключових активів зв’язок «актив → загроза → control → перевірка».
